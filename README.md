# EduShift AI

**Live Demo:** [View the deployed website](https://edu-shift-green.vercel.app/)

A B2B landing page for **EduShift**, a simulation-based learning platform designed to help organizations build practical decision-making skills through realistic digital simulations.

## Project Overview

EduShift transforms traditional learning into practical, simulation-based experiences where employees can practice making decisions in realistic business scenarios and measure their progress.

The goal of this project was to create a focused B2B landing page that helps decision makers quickly understand EduShift's value and encourages them to **Book a Demo**.

## Product Scope

* **Primary user:** B2B decision makers in banks, regulated companies, and corporate organizations
* **Primary task:** Understand EduShift and its simulation-based learning offering
* **Primary goal:** Book a Demo
* **Prototype question:** Can decision makers quickly understand EduShift's value and see how it can help their organization?

### Required Content

* Simulation-based learning
* Use cases
* Key benefits
* Measurable progress
* Product credibility
* Book a Demo CTA

### Explicit Exclusions

* No learner-facing product flows
* No dashboards
* No course management
* No backend functionality
* No frontend product application beyond the landing page

## Design Direction

The landing page follows a modern B2B SaaS direction with a strong focus on:

* Clear value communication
* Premium visual hierarchy
* Minimal but purposeful motion
* Simulation-focused visuals
* Strong CTA placement
* Responsive layouts
* Interactive visual elements

The visual system uses EduShift's brand direction with a clean white foundation, teal as the primary color, and orange as a supporting accent.

## Development Approach

The project was initially developed using **OpenAI Codex** to establish the core structure and implementation.

After the initial Codex credits were exhausted, the project was further refined and extended using **Manus**.

The second development phase focused on improving the visual quality, interactions, and overall presentation of the landing page. Additional technologies and interactive elements, including **Spline**, were introduced where they added value to the visual experience.


## Current Status

The current version is the **editable and active project version**.

## Evidence Status

The following distinction is maintained throughout the project:

* **Confirmed:** Existing EduShift product capabilities and available content
* **Assumed:** Information inferred from the product direction but not yet formally validated
* **Proposed:** Content or positioning created specifically for the landing page
* **Fictional:** Placeholder claims, metrics, testimonials, or customer evidence that have not been confirmed

Unverified metrics, customer results, testimonials, or claims should not be presented as factual product evidence.

## Project Goal

Create a focused B2B landing page that communicates:

> **AI. Simulate Decisions. Measure Progress.**

The experience should make the value of simulation-based learning understandable within a short browsing session and guide qualified visitors toward booking a demo.
